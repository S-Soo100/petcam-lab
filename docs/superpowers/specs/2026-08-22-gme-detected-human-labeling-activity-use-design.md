# GME 탐지 영상 휴먼 라벨링·활동량 활용 설계

> 상태: `OWNER_APPROVED / SPEC_REVIEW_PENDING`
>
> 승인일: 2026-08-22 KST
>
> 범위: GME 결과를 휴먼 라벨링, VLM 분석 입력 준비, 하이라이트 후보 순위에 연결

## 1. 결정

운영 영상은 기존처럼 GME가 분석한다. GME에서 게코가 탐지된 영상은 활동량과 관계없이 모두
휴먼 라벨링 대상으로 보낸다.

GME가 계산한 활동량은 다음 세 곳에서 적극 활용한다.

1. 휴먼 라벨링 큐의 같은 날짜 내 우선순위
2. VLM에 전달할 분석 구간과 프레임 선택
3. 하이라이트 후보의 우선순위

활동량은 행동 정답이나 제외 조건으로 사용하지 않는다.

## 2. 사용자 체험

- **[화면]** 라벨러는 어제 촬영된 게코 탐지 영상을 먼저 본다.
- **[조작]** 한 영상을 저장하고 다음 영상으로 이동한다.
- **[반응]** 같은 날짜에서는 GME 활동량이 높은 영상이 먼저 나오지만, 활동량이 낮은 탐지 영상도
  빠짐없이 이어서 나온다.
- **[감정]** 라벨러는 중요한 장면을 먼저 처리하면서도 게코가 나온 영상을 놓치지 않는다고 느낀다.

제품 사용자는 긴 원본 목록 대신 활동량이 높은 장면과 VLM이 의미를 확인한 장면을 하이라이트
후보로 먼저 보게 된다. 최종 행동명과 하이라이트 여부는 GME 단독으로 확정하지 않는다.

## 3. 데이터 흐름

```text
motion_clips
→ GME 분석
→ 게코 탐지됨
   ├─ 휴먼 라벨링 큐: 전량 편입
   ├─ VLM 입력 준비: 활동 구간 중심 프레임·시간대 선택
   └─ 하이라이트 후보: 활동량을 순위 신호로 사용
```

휴먼 라벨링 결과는 GT이고, GME 활동량과 VLM 결과는 prediction/evidence다. 서로 같은 필드를
덮어쓰지 않는다.

## 4. 휴먼 라벨링 큐 계약

- GME에서 게코가 탐지된 eligible 영상은 전부 편입한다.
- 날짜가 가장 강한 정렬 기준이다. `어제 → 전전날 → 전전전날` 순서를 유지한다.
- 같은 날짜 안에서는 GME 활동량이 높은 영상을 먼저 제시한다.
- 활동량이 0이거나 낮아도 게코가 탐지됐다면 큐에서 제외하지 않는다.
- 최초 사람 라벨 제출 전에는 GME 활동량, VLM 판정, 하이라이트 선정 사유를 화면에 노출하지 않아
  blind GT 계약을 유지한다.
- GME 미탐지·실패 영상의 기존 보존·감사 정책은 이번 변경에서 재설계하지 않는다.

## 5. VLM 활용 계약

GME가 제공하는 상태 구간과 활동량을 VLM의 의미 정답으로 전달하지 않는다. 대신 입력을 준비하는
시간축 힌트로 사용한다.

- 움직임 시작 전, 활동 구간, 움직임 종료 뒤의 프레임을 우선 선택한다.
- 긴 영상에서는 움직임이 집중된 구간을 우선 분석한다.
- 활동량이 낮은 탐지 영상도 휴먼 라벨링 대상에서 빠지지 않는다.
- VLM 결과는 별도 prediction ledger에 저장하며 사람 GT를 덮어쓰지 않는다.

## 6. 하이라이트 활용 계약

- 활동시간, 활동 구간 수, 가장 긴 활동 구간 등 기존 GME 수치를 하이라이트 후보 정렬에 사용한다.
- 카메라마다 장면과 검출 조건이 다르므로 raw 값 하나로 전체 카메라를 일괄 비교하지 않는다.
- GME 활동량은 후보 순위를 올리는 신호일 뿐이다.
- 실제 하이라이트 여부와 행동 의미는 VLM 분석 또는 사람 라벨을 함께 사용해 결정한다.
- 활동량이 낮다는 이유만으로 물 마시기·먹이 반응 같은 장면을 자동 탈락시키지 않는다.

## 7. 비목표

- GME 단독 행동 분류
- GME 미탐지 영상의 자동 삭제 또는 영구 제외
- 급수·급여·분무 위치 추정 시스템
- 새로운 사용자 입력이나 분무 기록 기능
- 복잡한 통합 점수 또는 신규 행동 클래스

## 8. 검증 기준

1. GME 게코 탐지 eligible 영상의 휴먼 라벨링 편입 누락이 0이다.
2. 큐는 날짜 우선, 같은 날짜에서는 활동량 우선으로 결정론적으로 정렬된다.
3. 활동량 0인 탐지 영상도 큐에 남는다.
4. 최초 사람 라벨 전에 GME/VLM 정보가 라벨러에게 노출되지 않는다.
5. VLM 입력 준비가 GME 활동 구간을 사용하되 사람 GT를 변경하지 않는다.
6. 하이라이트 후보 순위에 GME 활동량이 반영되며 GME 단독 확정은 없다.
7. 기존 GME 원장과 사람 GT provenance가 분리돼 재현된다.

## 9. 완료 조건

- 신규 영상에서 GME 탐지 → 휴먼 라벨링 큐 편입이 자동으로 이어진다.
- 같은 날짜 내 활동량 우선 정렬이 라벨링 화면에서 확인된다.
- VLM 분석 준비와 하이라이트 후보 생성에서 GME 활동량 사용 여부를 감사할 수 있다.
- production DB/R2 변경 전 migration·rollback·canary 절차를 별도 구현 계획에 명시한다.
