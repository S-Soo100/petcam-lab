# 라벨링 공통 영상 플레이어 설계

**상태:** 사용자 승인
**작성일:** 2026-08-01

## 1. 목표

라벨링 웹의 모든 실제 영상 재생 화면을 하나의 공통 플레이어로 통합한다. 영상은 화면에 준비되면 음소거 상태로 자동재생하고, 영상 내부 타임스탬프를 가리지 않도록 재생 조작부를 영상 바깥 아래에 둔다. 데스크톱 영상 영역은 최대 1200px까지 넓히고 모바일에서는 화면 폭에 맞춘다.

## 2. 사용자 체험

1. **[화면]** 검수 페이지가 열리면 넓은 영상 프레임과 그 아래 별도 조작바가 보인다.
2. **[반응]** 영상 URL이 준비되는 즉시 음소거 상태로 자동재생된다. 브라우저가 자동재생을 거부하면 정지 상태와 재생 버튼을 그대로 보여준다.
3. **[감정]** 영상 왼쪽 아래에 찍힌 촬영 타임스탬프가 조작바에 가려지지 않아 바로 확인할 수 있다.
4. **[조작]** 사용자는 영상 아래에서 재생·일시정지, 시간 이동, 음소거 전환, 전체화면을 조작한다.
5. **[반응]** 새 영상이나 다음 문제로 이동하면 새 영상도 같은 규칙으로 자동재생된다.

## 3. 범위

### 포함

- 라벨링 경로에서 실제 mp4를 재생하는 모든 `<video>` 사용처
- 기존 공용 `VideoPlayer`를 쓰는 GT·blind·tutorial·library·motion 상세 화면
- 직접 `<video>`를 쓰는 사건 이어짐, 자격검사, 경계 해결, quarantine 상세, router review 상세 화면
- 공통 플레이어 컴포넌트와 자동재생·조작 상태
- 영상이 있는 상세 화면과 역할 셸의 데스크톱 가용 폭 확대

### 제외

- 영상 목록의 thumbnail·정지 이미지
- API, DB, R2, GT, 사람 제출 payload 변경
- 영상 파일 인코딩·촬영 타임스탬프 자체 변경
- 영상 자동 제출이나 문제 자동 이동

## 4. 구조

`ReviewVideo` 클라이언트 컴포넌트를 영상 렌더링의 단일 진입점으로 둔다.

- `<video>`는 native `controls`를 사용하지 않는다.
- `autoPlay`, `muted`, `playsInline`, `preload="auto"`를 기본 계약으로 고정한다.
- 영상 프레임은 `w-full`, 검은 배경, 원본 비율 유지(`object-contain`)를 사용한다.
- 플레이어 아래 공통 조작바에 다음 기능을 둔다.
  - 재생·일시정지
  - 현재 시간 / 전체 시간
  - seek range
  - 음소거·소리 켜기
  - 전체화면
- 기존 `VideoPlayer`는 `ReviewVideo`를 감싸고, 현재의 1-frame 이동과 재생속도 기능은 보존한다.
- 직접 `<video>`를 쓰던 화면도 모두 `ReviewVideo`로 교체한다. 공통 컴포넌트 밖의 raw `<video>`는 정적 테스트로 금지한다.

## 5. 폭 계약

- 역할 셸은 데스크톱에서 navigation 220px와 영상 콘텐츠 최대 1200px를 함께 수용한다.
- 영상이 있는 상세 화면의 내부 `max-width`도 최대 1200px 계약을 막지 않게 조정한다.
- 사건 이어짐처럼 영상 두 개가 있는 화면은 넓은 데스크톱에서 2열, 좁은 화면에서 1열을 유지한다.
- 플레이어는 부모보다 커지지 않으며 모바일 수평 스크롤을 만들지 않는다.

## 6. 오류·접근성

- 자동재생 실패는 오류로 제출하거나 재시도 반복하지 않는다. 사용자가 재생 버튼으로 시작할 수 있다.
- 재생·음소거·전체화면 버튼은 접근 가능한 이름을 가진다.
- 시간 이동 range에는 현재 위치와 전체 길이를 반영한다.
- media error와 기존 `onLoadedMetadata`·`onError` 콜백 계약은 보존한다.
- 전체화면 API가 없거나 실패하면 페이지나 사람 판정 상태를 바꾸지 않는다.

## 7. 검증

1. RED→GREEN으로 공통 플레이어 기본 속성·조작 모델을 고정한다.
2. 라벨링 소스에서 공통 컴포넌트 외 raw `<video>`가 0개인지 감사한다.
3. 기존 VideoPlayer frame·속도 계약과 각 화면 렌더 테스트를 회귀 실행한다.
4. 전체 Web 테스트, TypeScript, production build를 통과한다.
5. production에서 사건 이어짐 화면과 단일 영상 상세 화면을 확인한다.
   - URL 준비 뒤 자동재생
   - 음소거 시작
   - 영상 아래 별도 조작바
   - 촬영 타임스탬프 비가림
   - 데스크톱 확장·모바일 무수평스크롤

## 8. 완료 조건

- 모든 라벨링 실제 영상이 공통 플레이어를 사용한다.
- 자동재생과 음소거 시작이 실브라우저에서 확인된다.
- native 조작바가 영상 위에 겹치지 않는다.
- 최대 1200px 데스크톱 폭과 모바일 축소가 확인된다.
- DB/R2/GT/사람 제출 변경이 없다.
